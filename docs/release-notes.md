Light 2 controls your existing VPN directly, with ⌃⌥⌘V to toggle and ⌃⌥⇧⌘V to open Shadowrocket. Includes configurable shortcuts, native settings, optional adaptive indicator color, conservative tunnel checks, and automatic updates.

Install into /Applications/Utilities. Setup: https://metalnakls.github.io/light/setup.html

This release is not Apple-notarized. See the setup guide if macOS blocks opening it.
