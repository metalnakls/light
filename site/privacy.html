Privacy

Light stores your selected VPN profile identifier, keyboard shortcuts, and preferences locally. It does not read or upload your VPN credentials or configuration.

While connected, health checks make HTTPS requests to Apple and Cloudflare through the selected VPN interface every 15 seconds. Those services receive normal connection metadata, including the tunnel’s public IP address. Light keeps only the current result and failure count in memory.

Optional adaptive coloring uses macOS Screen Recording permission to sample a tiny area beside the indicator. Samples are processed in memory; nothing is recorded to disk or transmitted.

Automatic updates contact GitHub for Light’s signed update feed and downloads. Sparkle system profiling is disabled. GitHub receives ordinary request metadata. You can disable update checks in Settings → About.

Light has no analytics, accounts, ads, or telemetry service.
