light

A light for your VPN.

Install

Light needs macOS 13 or later. Install and configure Shadowrocket first, including its VPN profile. Light controls that existing profile; it does not include a VPN subscription or server.

Download Light, unzip it, and move Light.app into Applications → Utilities. Open it once and choose your VPN profile in Settings.

Like Glass and Yina, this release is not Apple-notarized. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway. If macOS reports it as damaged, this command removes the download quarantine from Light only:

xattr -dr com.apple.quarantine /Applications/Utilities/Light.app

Alternatively, inspect and run the installer script. It downloads the latest release, checks its checksum and bundle signature, and installs into Utilities. It retains no backups.

curl -fsSL https://metalnakls.github.io/light/install.sh -o /tmp/install-light.sh
bash /tmp/install-light.sh

Use

  • ⌃⌥⌘V toggles the VPN.
  • ⌃⌥⇧⌘V opens Shadowrocket.
  • Click the dot to disconnect. It disappears after macOS confirms disconnection.
  • Right-click the dot or reopen Light for Settings. Both shortcuts can be changed there.

Remove conflicting assignments from Raycast or Shortcuts. Neither app is required by Light.

Read the indicator

A filled yellow dot means macOS reports a connection. A hollow dot means it is connecting or disconnecting. A red diamond means the VPN status is unavailable or both tunnel-bound HTTPS checks failed three times in a row. It is a connection warning, not a guarantee about privacy or every app’s traffic.

Health checks contact Apple and Cloudflare through the selected tunnel every 15 seconds. If macOS does not expose that tunnel interface, Light leaves the status inconclusive; it does not treat ordinary internet access as proof of VPN health.

Choose White in Appearance for a yellow background. On macOS 14 or later, optional adaptive coloring samples the menu bar beside the dot and switches to white on yellow. It requires Screen Recording permission; images remain in memory and are never saved or uploaded.

Updates

Update checks and automatic downloads are enabled by default. Light verifies signed updates from GitHub. Change these options or check manually in Settings → About. macOS may require approval before an update can be installed or opened.

Optional automation

Existing Shortcuts can call these commands. They now control the VPN itself, so remove any separate “Set VPN” action to avoid toggling twice.

open 'light://toggle'
open 'light://on'
open 'light://off'
open 'light://settings'
open 'light://shadowrocket'

The bundled helper also works:

/Applications/Utilities/Light.app/Contents/MacOS/lightctl toggle

To start Light automatically, add it in System Settings → General → Login Items.
